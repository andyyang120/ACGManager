## 简介

ACGManager（简称 ACMG）是一款专为 **Honey Select 2 / AI＊Shoujo / Koikatsu** 等 Illusion 系游戏打造的模组与角色卡综合管理工具。

如果你遇到过这些问题：

- 模组太多，不知道哪些重复、哪些冲突
- 下载了新角色卡，进游戏发现缺一堆 Mod，黑块满屏
- 同一个作者同一个角色，文件夹里塞了七八个版本，不敢删怕删错
- 想给角色卡换个封面，用 PS 打开怕破坏文件结构
- 硬盘空间不够，想把不常用的模组"移走"但游戏里还能用
- 游戏启动慢，加载大量模组耗时过长

那么 ACMG 就是为你准备的。它集**智能扫描、依赖分析、云端补缺、模组方案切换、角色卡去重、封面替换**于一体，让你告别手动整理文件的烦恼。

## 核心功能

### 1. 数据看板 —— 你的游戏资源全景指挥中心

打开软件后的默认首页，一眼看清你的全部家底：

- **六大卡片统计**：女角色卡、女服装卡、男角色卡、男服装卡、场景卡、总汇总（实时数据库读取，点击数字直接跳转对应管理页）
- **本地模组统计**：汇总、私密、启用、缺失、可修复、冲突六项指标
- **插件仓库统计**：已入库、已启用、缺失数量
- **快捷目录**：一键直达游戏根目录、UserData、Studio、截图、Mods、Plugins 等常用文件夹
- **系统公告**：顶部显示最新官方公告，带"新"标记提醒，网址自动识别为超链接
- **一键启动**：底部集成「启动游戏」「启动工作室」「启动 Initial Settings」按钮

### 2. 卡片管理 —— 从入库到去重，管理上万张角色卡

**智能入库与浏览**
- 自动扫描指定目录（支持多目录）的所有 `.png` 角色卡
- 八类自动分拣：全部 / 女角色 / 男角色 / 女装 / 男装 / 场景卡 / 失效卡 / 重复卡
- 分页浏览，带缩略图预览（女角色 192px，场景卡 288px 宽屏）
- 支持按卡名/文件名模糊搜索，按名称、修改时间升降序排列
- 缺失标记：卡片右上角状态圆点——**绿色 = 依赖齐全**，**红色 = 本地缺 Mod**

**依赖分析 —— 一眼看穿卡片"底细"**
选中任意卡片，右侧实时显示：
- **依赖 Mod 列表**：按部位分类（衣服、袜子、鞋子等），绿色 = 本地已安装，红色 = 本地缺失，浅绿色 = 云端库可补齐
- **依赖 Plugin 列表**：显示需要哪些插件支持
- **文件信息**：完整路径、文件大小、修改时间、作者 ID（data_id）
- 快捷操作：点击 📁 直接打开文件所在位置；点击 📋 复制完整路径

**一键补齐 —— 三种姿势修复缺失**
- 单卡补齐：选中一张卡 → 点「下载缺失模组」
- 多选批量补齐：勾选多张卡 → 统一分析缺失并下载
- 全页补齐：点「全部补齐」，当前标签页所有缺失的公共 Mod 一次性拉齐
- 自动去重下载：同一张 Mod 被多张卡依赖时只下载一次

**高级去重 —— 专治"同一个卡存了七八份"**
入口：工具箱 → 卡片去重（或卡片页「高级去重」）

扫描规则（可多选，交集匹配）：
- `data_id` 重复（同作者同角色 ID）
- `file_hash` 重复（文件内容完全一致）
- `card_data_hash` 重复（仅卡片数据部分相同，可能不同封面）
- 全部穿戴相同 / 服装穿戴相同

智能筛选模式：
- **无依赖原始卡**：不依赖任何第三方 Mod 的纯净卡
- **只依赖云端**：所有缺失 Mod 都能在云端库找到，可全自动修复
- **高级私密卡**：依赖了本地没有且云端也没有的 Mod（私人定制或小众内容）

清理与导出：
- 自动选择保留：一键自动选中每组重复里"修改时间最新"的那张
- 安全删除：移入回收站，误删可还原
- 分类结构导出：按 `chara/female`、`chara/male`、`coordinate/female`、`studio/scene` 标准目录结构导出纯净/公开/私密卡组

### 3. 模组管理 —— 本地 + 云端双模式

**本地模组**
- 自动扫描 `mods` 目录，解析所有 `.zipmod` 文件
- 卡片式展示：模组名称、作者、版本、文件大小、冲突状态（GUID 冲突标红警告）
- 支持按修改时间、文件大小、作者排序
- 增量扫描：第二次扫描只处理新增/修改文件，配合哈希缓存，上万模组秒级更新

**云端模组**
- 浏览服务器公开模组库，分 AIS / HS2 标签
- 绿色边框 = 本地已有，红色边框 = 本地没有
- 支持批量选中后「下载选中」

**高级模组管理（Beta v0.3.3+）**
- 按部位精准分类：全部 / 服装 / 发型 / 饰品 / 妆容与身体 / 工作室
- 左侧实时统计件数（如 `女-上衣[357件]`、`男-鞋子[128件]`）
- 右侧完整元数据面板：Author / Version / Category / Kind / GUID / 文件路径 / 大小 / zipmod 内部文件列表
- 支持批量勾选、批量删除（带确认弹窗，删除到回收站）

### 4. 超级加速 —— 模组方案切换，启动快人一步

通过**软链接/硬链接**技术，将不同模组组合保存为"方案"，切换时无需复制文件，瞬间完成。

典型使用场景：
- **方案 A**：日常游玩（100 个常用模组）
- **方案 B**：拍照专用（500 个高质量服装模组）
- **方案 C**：极简模式（只保留基础模组）

操作流程：
1. 点击「添加方案」，输入名称
2. 从本地模组库勾选该方案要包含的模组
3. 点击「全量部署」，软件创建链接文件
4. 想用时点击「激活方案」，不用时点击「取消方案」或「还原路径」

&gt; 配合 **BepisPluginSuper** 插件使用，支持**动态热重载**（快捷键 `Ctrl+D`），游戏内即可刷新加载新 Mod，无需重启游戏。

### 5. 插件管理 —— DLL 统一管理

- 扫描 `BepInEx/plugins/` 目录下的 DLL 文件
- 冲突检测：相同 GUID 标红提示
- 一键启用/禁用插件
- 卡片样式与模组管理一致，方便识别

### 6. 工具箱

**卡片封面替换**
- 无损替换角色卡封面 PNG
- 左侧拖入新封面图，右侧拖入目标角色卡
- 自动嵌入新图到 PNG 数据区，保留所有卡片内部数据不变
- 输出文件名带日期后缀，可选勾选"备份原图"

**依赖提取**
- 自动分析角色卡依赖的模组和插件清单

## 下载与安装

1. 从 Releases 下载最新版压缩包（约 6MB，免安装）
2. 解压到任意文件夹（**建议与游戏放在同一磁盘**，超级加速性能最佳）
3. 双击 `ACGManagera.exe` 运行

**首次启动配置**：
- 设置游戏根目录（选择 `HoneySelect2.exe` 所在文件夹）
- 软件自动识别 `mods`、`UserData\chara` 等路径
- 登录账号（支持 OAuth 统一认证）

## 快速上手

### 第一步：完成基础配置
进入「数据看板」→ 点击「设置游戏根目录」→ 选择游戏安装路径 → 点击右上角「扫描」等待建库完成。

### 第二步：浏览卡片
进入「卡片管理」→ 切换「女角色」标签 → 点击任意卡片查看右侧依赖信息。红点 = 缺 Mod，点击「下载缺失模组」自动补齐。

### 第三步：整理重复卡
进入「工具箱」→「卡片去重」→ 添加扫描目录 → 勾选去重规则 → 扫描 → 自动选择保留最新 → 删除未选中项（移入回收站）。

### 第四步：体验超级加速
进入「超级加速」→「添加方案」→ 勾选常用模组 →「全量部署」→ 随时点击「激活/取消方案」切换模组组合。

## 注意事项

1. **超级加速** 首次创建软链接可能需要管理员权限，软件会提示自动重启获取权限。
2. **删除操作**（去重、批量删除）默认移入系统回收站，误删可恢复。
3. **预览图** 依赖缩略图缓存，若显示空白请先执行扫描。
4. **数据库加密**：本地数据库采用 SQLCipher 加密，卡库路径、作者信息、依赖关系不会明文暴露。
5. **扫描过程中** 请勿频繁切换页面，避免中断导致解析不完整。
